# v2026.9.9

AI agents and tools can read these release notes as [plain Markdown](https://raw.githubusercontent.com/openclaw/openclaw/main/CHANGELOG/2026.9.9.md).

OpenClaw 2026.9.9 adds GPT-6.1 Sol catalog support for eligible accounts, fixes update failures and missing iMessage replies, and keeps an old scheduled job from interrupting a newer conversation.

**Release scale:** 16 pull requests, 11 direct commits, and 18 contributors.

## Web UI

- **Windows workspaces.** **New workspace** can create an empty workspace and start its session [natively on Windows](/platforms/windows#native-windows-cli-and-gateway) without changing global Git settings. Install Git for Windows and put it on `PATH` first. Deeply nested paths can still hit a separate Git limit. [#164202](https://github.com/openclaw/openclaw/pull/164202)

## Updates and Maintenance

- **Update completion.** Active database writes no longer block an update's ownership checks, and updates from affected older builds preserve the files needed to finish plugin migrations after package replacement. [30c180a](https://github.com/openclaw/openclaw/commit/30c180a4ece3ae149286b80174b0edb526aa88ae) by [@RomneyDa](https://github.com/RomneyDa), [ecac0d3](https://github.com/openclaw/openclaw/commit/ecac0d3f0bdca5d127df1b4f269d007714697ce4).
- **Backups on FUSE storage.** Backups and restores used by updates, Doctor and rollback accept timestamp-only drift after checking that the contents still match. See the [container upgrade guidance](/install/docker#upgrading-container-images). [3ecb62a](https://github.com/openclaw/openclaw/commit/3ecb62aad260e3f871e7ae83d446404abfc83bed)
- **Memory-cache migration.** Doctor skips oversized or malformed entries instead of aborting an older cache conversion. It reports warnings, retains source data and lets skipped cache entries rebuild. Before upgrading an older database, stop writers and take a verified backup as described in the [migration guidance](/reference/database-schemas/agent-schema-history#compact-agent-payload-storage). [#164303](https://github.com/openclaw/openclaw/pull/164303)

## Messaging

- **Telegram Control UI.** Use `/controlui` in a bot DM for the Mini App; `/dashboard` creates or updates a session dashboard. Update saved commands, shortcuts and custom menu descriptions, then request a fresh `/controlui` button. Mini App access requires an explicit numeric Telegram ID in the account's owner access list or a referenced Telegram access group; wildcards and usernames do not qualify. Administrators should add affected users' IDs while retaining existing entries. See the [migration guide](/channels/telegram/mini-app#upgrading-from-dashboard). [#161369](https://github.com/openclaw/openclaw/pull/161369) by [@mmaps](https://github.com/mmaps), with command separation by [@joshavant](https://github.com/joshavant).
- **iMessage replies.** Fixed ordinary conversations that finished generating an answer without sending the final reply. [#163742](https://github.com/openclaw/openclaw/pull/163742), with coauthors [@VACInc](https://github.com/VACInc) and [@Kimiyu-186](https://github.com/Kimiyu-186).
- **Discord task results.** A delegated task that posts its result to the requester's thread and then finishes silently can count as delivered instead of showing a failed status. Webhook replies also follow the thread's webhook and persona. [#163756](https://github.com/openclaw/openclaw/pull/163756) by [@MertBasar0](https://github.com/MertBasar0), reported by [@stuart-minion-ai](https://github.com/stuart-minion-ai) and landed by [@obviyus](https://github.com/obviyus).
- **Queued messages.** Cancelling a message that has not started processing no longer prevents the active reply from finishing. A [remaining cancellation issue](https://github.com/openclaw/openclaw/pull/164230#issuecomment-5968104212) can let pending plugin work continue while a session is reset or deleted. [#164230](https://github.com/openclaw/openclaw/pull/164230) by [@vincentkoc](https://github.com/vincentkoc).

## Models and Providers

- **GPT-6.1 Sol.** The managed Codex catalog recognizes GPT-6.1 Sol for eligible accounts. Access depends on your account and configured [Codex runtime](/providers/openai/runtimes), with complementary provider support described in [#161400](https://github.com/openclaw/openclaw/pull/161400) as context. Turns repeatedly refused by Codex's Guardian checks can also finish without hanging until timeout. [65e89fc](https://github.com/openclaw/openclaw/commit/65e89fcc277cd26cf2f763112eaeb36325834a0e) by [@IstiqlalBhat](https://github.com/IstiqlalBhat), with coauthor [@RomneyDa](https://github.com/RomneyDa) and credited contributor [@fuller-stack-dev](https://github.com/fuller-stack-dev).
- **Managed Codex runtime.** OpenClaw bundles Codex 0.160.0 with upstream startup and logging fixes. Updating a separate Codex CLI does not update this managed runtime. [#163560](https://github.com/openclaw/openclaw/pull/163560) by [@vincentkoc](https://github.com/vincentkoc).

## Automations and Scheduling

- **Scheduled jobs.** An old job's timeout no longer cancels a newer conversation using the same session or clears its tools, fixing the wrong-conversation cancellation in the [reported incident](https://github.com/openclaw/openclaw/issues/163568). [#163704](https://github.com/openclaw/openclaw/pull/163704), thanks to [@jayzhou2309](https://github.com/jayzhou2309) for the fix and tests, [@AXEG0](https://github.com/AXEG0) for reporting it, [@ekinnee](https://github.com/ekinnee) and [@MasterSwords1](https://github.com/MasterSwords1) for investigating the cancellation boundary, and [@obviyus](https://github.com/obviyus) for validation and landing work.
- **Background job startup.** Skill Workshop reviews and scheduled jobs tied to their agent's configured workspace avoid repeated plugin setup that could stall chat or disconnect the Control UI, including during conversation compaction. [File access stays limited to the task folder](/plugins/architecture#plugin-metadata-snapshot-and-lookup-table). [#164049](https://github.com/openclaw/openclaw/pull/164049)

## Security and Privacy

- **Windows MXC sandbox.** The optional [MXC sandbox](/plugins/reference/mxc) can activate and run tools on compatible Windows hosts without the retired Windows service. Custom executors need MXC 0.8.0 compatibility and `--probe` support; update yours or remove the override, then restart the Gateway. The plugin requires OpenClaw plugin API 2026.9.6 or newer. Degraded isolation can warn without blocking activation. Keep secrets out of MXC command arguments and environment values because host users with process-inspection rights can read them. [#158303](https://github.com/openclaw/openclaw/pull/158303), thanks to [@paulcam206](https://github.com/paulcam206).
- **Input policies on paired computers.** Plugin [input policies](/plugins/hooks#choose-a-hook) can block OpenClaw requests before they run on paired computers, including when the policy errors. They inspect the prompt and history available at the Gateway. Use a supported local runner if your policy needs system instructions or skill context assembled later on the paired computer. Blocked requests save a redacted message when the Gateway controls saving; input already saved by the calling transport remains in the transcript. This change applies to OpenClaw node workers, not Codex or Copilot. [#164270](https://github.com/openclaw/openclaw/pull/164270)

## Other Bug Fixes

- **Windows session storage.** Sessions can be created when a Windows junction or another filesystem alias points to their database, avoiding a false ownership error. [bec0cfd](https://github.com/openclaw/openclaw/commit/bec0cfd9a21a1e6d5900fd0ac859c23f56b45d87) by [@cestercian](https://github.com/cestercian), with coauthor [@RomneyDa](https://github.com/RomneyDa).
- **Command shutdown.** A workaround for a Node shutdown bug prevents affected commands from hanging after printing their output. It also covers the Gateway service, hook relays and macOS node worker. Some commands may take longer; explicit compiler overrides can bypass the workaround. See the [Node compatibility guide](/install/node-compatibility#v8-compiler-settings). [#163788](https://github.com/openclaw/openclaw/pull/163788)
- **Sessions on paired computers.** Routine capacity and status updates no longer make a connected session host appear unavailable, stalling or failing other [sessions on that computer](/nodes/session-hosting). Update the Gateway to apply the fix. [#164087](https://github.com/openclaw/openclaw/pull/164087)
