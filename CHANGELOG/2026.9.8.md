## 2026.9.8


### v2026.9.8

For formatted release notes, [read this release on the docs site](https://docs.openclaw.ai/releases/2026.9.8).

OpenClaw 2026.9.8 fixes missing delegated replies, reduces unnecessary memory use in larger Codex setups, and addresses failed updates and Windows startup problems.

**Release scale:** 43 pull requests, 12 direct commits, and 8 contributors.

#### Web UI

- **Browser tabs after updates.** The bundled Control UI keeps older tabs loading while their version's files are retained. Older tabs may still need a reload when those files expire; see the [Control UI limits](https://docs.openclaw.ai/web/control-ui/development). [#163478](https://github.com/openclaw/openclaw/pull/163478), backporting [#163090](https://github.com/openclaw/openclaw/pull/163090) and [#163099](https://github.com/openclaw/openclaw/pull/163099), with contributions from [@vincentkoc](https://github.com/vincentkoc).
- **Session assignment.** Pressing Enter on “Assign to…” after hovering opens the menu without accidentally assigning the session. [#163467](https://github.com/openclaw/openclaw/pull/163467), backporting [#161393](https://github.com/openclaw/openclaw/pull/161393), coauthored by [@RomneyDa](https://github.com/RomneyDa) and [@vincentkoc](https://github.com/vincentkoc).
- **Silent-reply help.** Twenty existing translations now explain that silence settings apply to groups, while direct chats and internal sessions require a reply. [#163409](https://github.com/openclaw/openclaw/pull/163409), using translations from [#162942](https://github.com/openclaw/openclaw/pull/162942), with contributions from [@vincentkoc](https://github.com/vincentkoc).

#### Updates and Maintenance

- <a id="update-recovery-sources"></a>**Update recovery.** Repair preserves plugin allowlists and enabled entries, lets a fresh Doctor finish pending migration confirmations, and clears obsolete migration warnings. For Windows 2026.9.4 recovery, back up first and follow the [independent-shell procedure](https://docs.openclaw.ai/cli/update), preserving the original service account, npm prefix, profile and overrides. Stop the old processes, upgrade manually, run the new Doctor, then restart and verify. [#162959](https://github.com/openclaw/openclaw/pull/162959), backported by [@RomneyDa](https://github.com/RomneyDa), includes work by [@VACInc](https://github.com/VACInc), [@obviyus](https://github.com/obviyus) and [@ericcaiwx-star](https://github.com/ericcaiwx-star). The bundle also supplies the startup, Telegram, skills, provider, TLS and history fixes below. Upstream context includes [#160344](https://github.com/openclaw/openclaw/pull/160344), [#160193](https://github.com/openclaw/openclaw/pull/160193), [#160718](https://github.com/openclaw/openclaw/pull/160718), [#160702](https://github.com/openclaw/openclaw/pull/160702), [#161946](https://github.com/openclaw/openclaw/pull/161946), [#161832](https://github.com/openclaw/openclaw/pull/161832), [#162290](https://github.com/openclaw/openclaw/pull/162290), [#162321](https://github.com/openclaw/openclaw/pull/162321), [#162912](https://github.com/openclaw/openclaw/pull/162912), [#161260](https://github.com/openclaw/openclaw/pull/161260), [#162841](https://github.com/openclaw/openclaw/pull/162841), [#160137](https://github.com/openclaw/openclaw/pull/160137), [#162304](https://github.com/openclaw/openclaw/pull/162304) and [#162394](https://github.com/openclaw/openclaw/pull/162394).
- <a id="platform-update-sources"></a>**Windows and macOS updates.** Windows retries temporary file locks and preserves the installed package if retries run out. macOS recognizes aliased installation paths during npm replacement, including while the old package directory is absent. These fixes require the updated updater; use the [update guidance](https://docs.openclaw.ai/cli/update) if an older version's first upgrade fails. [#163074](https://github.com/openclaw/openclaw/pull/163074), backported by [@RomneyDa](https://github.com/RomneyDa), includes work by [@fuller-stack-dev](https://github.com/fuller-stack-dev) and [@obviyus](https://github.com/obviyus); [#163481](https://github.com/openclaw/openclaw/pull/163481), with work by [@vincentkoc](https://github.com/vincentkoc), backports [#163479](https://github.com/openclaw/openclaw/pull/163479). The first bundle also supplies the delegated-reply, Codex, shutdown and redaction fixes below. Upstream context includes [#161003](https://github.com/openclaw/openclaw/pull/161003), [#162076](https://github.com/openclaw/openclaw/pull/162076), [#162231](https://github.com/openclaw/openclaw/pull/162231), [#162352](https://github.com/openclaw/openclaw/pull/162352), [#162403](https://github.com/openclaw/openclaw/pull/162403), [#162387](https://github.com/openclaw/openclaw/pull/162387), [#162616](https://github.com/openclaw/openclaw/pull/162616), [#162810](https://github.com/openclaw/openclaw/pull/162810), [#162967](https://github.com/openclaw/openclaw/pull/162967), [#162227](https://github.com/openclaw/openclaw/pull/162227), [#162567](https://github.com/openclaw/openclaw/pull/162567), [#163129](https://github.com/openclaw/openclaw/pull/163129) and activation-path counterpart [#163086](https://github.com/openclaw/openclaw/pull/163086). [Update rehearsal](https://docs.openclaw.ai/install/updating) also preserves row identities while avoiding redundant database copies.
- **Startup and shutdown.** Direct and container starts prevent competing Gateways from sharing stored state, Windows avoids hangs from long cache paths, and maintenance retries brief database contention. Shutdown can finish while memory synchronization is idle without interrupting an active write. [Update recovery sources and credits](https://docs.openclaw.ai/releases/2026.9.8#update-recovery-sources), [platform update sources and credits](https://docs.openclaw.ai/releases/2026.9.8#platform-update-sources).
- **Configuration reloads.** Accepted work can finish through [connection-policy reloads](https://docs.openclaw.ai/gateway/configuration/hot-reload) while access remains valid. Clients reconnect for new requests; revoked access still cancels affected work, and authentication-mode or listener changes require a restart. See [trusted-proxy guidance](https://docs.openclaw.ai/gateway/trusted-proxy-auth). [#163174](https://github.com/openclaw/openclaw/pull/163174), backported by [@RomneyDa](https://github.com/RomneyDa) from [#160909](https://github.com/openclaw/openclaw/pull/160909).

#### Messaging

- **Delegated replies.** Results return to the original requester once, immediately or when work finishes. [Internal sessions](https://docs.openclaw.ai/concepts/messages) return a result or keep working instead of ending silently. Custom workflows using silent completion or automatic agent back-and-forth must handle returned results and use explicit follow-up or message calls; `REPLY_SKIP` and `ANNOUNCE_SKIP` no longer suppress returned text. [Doctor migrates the retired silence settings](https://docs.openclaw.ai/gateway/doctor/config-migrations), preserving group-chat silence. [Sources and credits](https://docs.openclaw.ai/releases/2026.9.8#platform-update-sources).
- **Replies after reloads and wake.** Fixed a listener failure, reported with Matrix, that left channels appearing connected but unable to reply after recovery finished. [#163504](https://github.com/openclaw/openclaw/pull/163504), backporting [#163268](https://github.com/openclaw/openclaw/pull/163268). Thanks to upstream author [@scotthuang](https://github.com/scotthuang) and contributor [@vincentkoc](https://github.com/vincentkoc).
- **Telegram cleanup and previews.** Doctor archives verified empty retired binding files, leaving nonempty or uncertain files for review and preserving originals if archiving fails. Queued previews that track their writer reject stale edits after that writer is replaced. [Sources and credits](https://docs.openclaw.ai/releases/2026.9.8#update-recovery-sources).

#### Skills

- **Skills from read-only installations.** Refreshing POSIX skill copies in sandboxed workspaces and Claude CLI sessions now works when copied directories inherited read-only permissions, without changing the original installation. [Sources and credits](https://docs.openclaw.ai/releases/2026.9.8#update-recovery-sources).

#### Models and Providers

- **GPT-6.1 Sol.** This release includes preparatory work for [GPT-6.1 Sol](https://docs.openclaw.ai/providers/openai/models), but support was not complete. [#161400](https://github.com/openclaw/openclaw/pull/161400), [#163132](https://github.com/openclaw/openclaw/pull/163132), backported by [@RomneyDa](https://github.com/RomneyDa).
- **Local models on Windows.** Managed llama.cpp setup can supply missing Microsoft runtime files beside the server for local chat and embeddings, without a system-wide runtime installation. If startup still fails, rerun setup or configure a compatible server manually. [#163093](https://github.com/openclaw/openclaw/pull/163093) and its backport [#163128](https://github.com/openclaw/openclaw/pull/163128), both by [@RomneyDa](https://github.com/RomneyDa).
- **Codex resource use.** Idle agents start session-catalog processes only when requested, and compatible agents share captured settings to reduce duplicate memory use in larger [native Codex setups](https://docs.openclaw.ai/plugins/codex-harness). [Shell snapshots](https://docs.openclaw.ai/tools/exec) also keep a bounded in-memory history. [Update recovery sources and credits](https://docs.openclaw.ai/releases/2026.9.8#update-recovery-sources), [platform update sources and credits](https://docs.openclaw.ai/releases/2026.9.8#platform-update-sources).
- **Anthropic background results.** Turns wait for background command, agent and workflow results to be picked up, fixing hangs and premature completion. [Sources and credits](https://docs.openclaw.ai/releases/2026.9.8#update-recovery-sources).

#### Browser and Computer Use

- **Native app readiness.** API-key users of [Codex Computer Use](https://docs.openclaw.ai/plugins/codex-computer-use) can check desktop app access without an unrelated browser sign-in blocking the check. Browser control still requires its own authentication. [Sources and credits](https://docs.openclaw.ai/releases/2026.9.8#windows-session-sources).

#### Security and Privacy

- **Local TLS checks.** HTTPS health checks preserve managed proxy settings and verify the configured certificate fingerprint on every connection. [Sources and credits](https://docs.openclaw.ai/releases/2026.9.8#update-recovery-sources).
- **Log redaction.** Fixed missed sensitive values in long, obfuscated log assignments when running on Bun. [Sources and credits](https://docs.openclaw.ai/releases/2026.9.8#platform-update-sources).

#### Other Bug Fixes

- <a id="windows-session-sources"></a>**Windows sessions.** Fixed an error that blocked opening stored conversations and preparing scheduled agent sessions. [#162931](https://github.com/openclaw/openclaw/pull/162931), authored by [@RomneyDa](https://github.com/RomneyDa), backports [#160075](https://github.com/openclaw/openclaw/pull/160075), which references fixes for [#157067](https://github.com/openclaw/openclaw/issues/157067) and [#159339](https://github.com/openclaw/openclaw/issues/159339). The same bundle includes the native app readiness repair from [#162467](https://github.com/openclaw/openclaw/pull/162467) and clearer workspace-recovery diagnostics.
- **Session history repair.** Long chains of linked sessions no longer crash repair with a stack overflow; existing history and transcript ownership are preserved. [Sources and credits](https://docs.openclaw.ai/releases/2026.9.8#update-recovery-sources).
